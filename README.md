# Harmony Horizon

Harmony Horizon is a Minecraft plugin designed to enhance the gameplay experience by providing a variety of features that cater to different playstyles. It includes automation tools for factory setup, exploration utilities for unique enemy encounters, aesthetic enhancements for building and design, and player assistance for new users. The plugin is built for Minecraft version 1.21 and is compatible with PaperMC.

## Install

1. Download the plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart your Minecraft server.

## Use

1. Start your Minecraft server.
2. Use the `/ciao` command to greet yourself and verify the plugin is working.
